# Student Grade Management System

A command-line application written in Python for recording student names, IDs and marks, automatically assigning letter grades, viewing all records as a table, updating existing marks, and exporting everything to a CSV file.

All data is stored locally in a JSON file (`record.json`), which the program creates automatically on first run. No database or internet connection is required.

## Features

- **Add student records** — name, unique ID and marks, with input validation.
- **Automatic grading** — a letter grade is calculated from the marks entered.
- **View records** — all students displayed in a formatted table.
- **Update marks** — look a student up by name and change their marks; the grade is recalculated.
- **CSV export** — write all records to `Record CSV.csv` for use in Excel or Google Sheets.
- **Persistent storage** — records are saved to `record.json` and reloaded every time the program starts.

## Setup Instructions

### Step 1 — Get the project files

If the project is on GitHub, clone it:

```bash
git clone https://github.com/nkk-854/Vityarthi_Py_Project
cd Vityarthi_Py_Project
```

Otherwise, download the files and open a terminal in the folder containing `main.py`.

### Step 2 — Create a virtual environment (recommended)

A virtual environment keeps this project's packages isolated from the rest of your system.

**Windows (Command Prompt or PowerShell):**

```bash
python -m venv venv
venv\Scripts\activate
```

**macOS / Linux:**

```bash
python3 -m venv venv
source venv/bin/activate
```

Once activated, your prompt will be prefixed with `(venv)`.

> To leave the virtual environment later, run `deactivate`.

### Step 3 — Install dependencies

This project uses **pandas** for table display and CSV export.

```bash
pip install -r requirements.txt
```

If you do not have `requirements.txt`, install the dependency directly:

```bash
pip install pandas
```

Confirm the install succeeded:

```bash
python -c "import pandas; print(pandas.__version__)"
```

## Usage Guide

At the prompt, enter the number of the option you want and press Enter.

### 1. Add Credentials

Adds a new student. You will be asked for:

- **Name** — any text, e.g. `Ananya Sharma`
- **Unique ID** — any text or number, e.g. `S101`
- **Marks** — a whole number between 1 and 100. Invalid values are rejected and re-prompted.

The grade is calculated automatically and the record is written to `record.json`.

### 2. View Credentials

Prints every stored record as a table:

```
----- Student Records Table -----
        Name Unique ID  Marks Grade
Ananya Sharma      S101     92     A
   Rahul Nair      S102     67     C
```

### 3. Update Credentials

Enter the **exact name** of an existing student, then the new marks. The grade is recalculated and the file is saved. If no student matches, you will see `Student not found.`

> Name matching is case-sensitive and must match exactly — `rahul nair` will not match `Rahul Nair`.

### 4. To create CSV File

Exports all records to `Record CSV.csv` in the project folder. Running this again overwrites the existing file.

### 5. Exit

Closes the program.

### Example session

```
Choose from the given option [1-4]: 1
Enter Name: Ananya Sharma
Enter Unique ID: S101
Enter marks: 92
Student added successfully.
```

There is no configuration file or environment variable to set — the project runs with its defaults out of the box.

If you want to change where data is stored, edit the constant near the top of `main.py`:


## Troubleshooting

**`ModuleNotFoundError: No module named 'pandas'`**
The dependency is not installed, or the virtual environment is not active. Activate it (see Step 2) and run `pip install -r requirements.txt` again.

**`python: command not found`**
Use `python3` instead, or add Python to your system PATH. On Windows, re-run the Python installer and tick "Add Python to PATH".

**`venv\Scripts\activate` fails on Windows PowerShell**
PowerShell may block scripts. Run this once, then try again:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

**`Permission denied` when saving `record.json` or the CSV**
Make sure the CSV file is not open in Excel, and that you have write access to the project folder.

**Records seem to have disappeared**
The program reads `record.json` from the current working directory. Run `python main.py` from inside the project folder rather than from a parent directory.
